# 📚 Univ Resource Hub

Univ Resource Hub is a platform designed to help students and faculty manage and share university resources efficiently.  
It provides tools for uploading, organizing, and accessing study materials, assignments, and important documents in one place.

---

## 🚀 Features
- Upload and manage resources
- Organize by course/subject
- Search and filter functionality
- Admin panel for moderation
- Secure access controls

---

## 🛠️ Tech Stack
- **Frontend:** NEXT.js, TailwindCSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Version Control:** Git & GitHub
